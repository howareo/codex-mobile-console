# Codex app-server protocol baseline

This directory contains JSON Schema files captured from the Codex app-server protocol baseline `0.147.0-alpha.6.5`.

The directory name is intentionally version-neutral: this is a protocol reference for compatibility probes and type review, not an application release and not a runtime pin. The gateway resolves the Codex binary installed on the Windows host at startup.

Do not treat the source schema version as the version of Codex Desktop, the shared app-server, or this project.
